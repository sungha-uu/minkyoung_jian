# 꾼의 주방 · Recipe Archive

서문시장 **섹시한 꾼만두**의 레시피, 버전, 개선 기록과 메뉴 개발 계획을 관리하기 위한 모바일 우선 웹 대시보드입니다.

> 현재 등록된 모든 계량과 조리법은 UI 검토용 샘플이며 실제 영업용 레시피가 아닙니다.

## 로컬 확인

정적 파일만 사용하므로 `index.html`을 열거나 간단한 로컬 서버에서 확인할 수 있습니다.

```powershell
python -m http.server 4173
```

## 데이터 구조

- `recipe-data.js`: 가게 및 수집 레시피, 배합, 버전, 개선 메모
- `data.js`: 직원용·손님용 조리 가이드
- `app.js`: 검색, 분류, 배수 환산, 버전 기록 등 화면 동작
- `styles.css`: 반응형 대시보드 디자인
- `assets/`: 메뉴 이미지와 로컬 서체

GitHub Pages는 `main` 브랜치의 루트 폴더를 직접 배포합니다. `main`에 반영하면 잠시 뒤 사이트가 자동으로 갱신됩니다.

## 정보 구조

1. 가게 레시피 관리와 개선 이력
2. 모든 수집 레시피와 즐겨찾기 1·2
3. AI 레시피 개선, 재료 분석, 신메뉴 개발, 테스트 계획서
4. 직원용 표준 조리법과 손님용 포장 조리 안내
